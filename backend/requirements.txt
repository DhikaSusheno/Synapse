# --- runtime dependencies yang sebelumnya hilang ---------------------------
# Keempatnya di-import oleh kode produksi dan TIDAK ikut ter-install lewat
# dependency fastapi, jadi `pip install -r requirements.txt` menghasilkan
# backend yang tidak bisa start. Lihat issue #61.
#
# cryptography  auth.py membutuhkannya untuk Fernet; dipakai encrypt_token()
#              dan decrypt_token() yang menyimpan GitHub PAT + API key LLM.
#              Tanpa ini: ModuleNotFoundError saat import auth, backend mati total.
# requests     main.py memakainya untuk memanggil GitHub API (/api/github/*).
#              Tanpa ini: endpoint tersebut balas 500 saat dipanggil.
# numpy        main.py memakainya untuk cosine similarity di RAG (/api/rag/*).
# httpx        main.py memakainya sebagai AsyncClient untuk panggilan LLM
#              provider yang tidak diblokir.
#
# pins mengikuti versi yang sudah diverifikasi jalan di test suite.
# CATATAN numpy: sengaja di-pin 2.4.6, bukan 2.5.x. NumPy 2.5.0 dan
# seterusnya memerlukan Python >=3.12 sedangkan CI memakai Python 3.11, jadi 2.5.x akan gagal install
# di CI. 2.4.6 adalah rilis terakhir yang masih menyediakan wheel cp311.
